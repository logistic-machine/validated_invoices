# Envios Logísticos (Python)

Este projeto contém ferramentas desenvolvidas para otimizar fluxos de trabalho no setor de logística, integrando Excel, Outlook e GRC (extensão do SAP).

## 🚀 Funcionalidades

### 2. Automação de E-mails com Anexos Dinâmicos
- **Problema:** Envio manual de relatórios para mais de 20 fornecedores diferentes.
- **Solução:** Integração via `win32com` e `xlwings` que atualiza os dados do Excel e envia e-mails personalizados automaticamente.

## 🛠️ Tecnologias Utilizadas
- **Python 3.x**
- **Pandas:** Manipulação de grandes volumes de dados.
- **Xlwings / Win32com:** Automação de Office (Excel e Outlook).
- **Openpyxl:** Formatação de planilhas profissionais.

## 📈 Resultados
- Redução de 80% no tempo gasto em tarefas manuais repetitivas.
